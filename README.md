# VK Music TUI — VK Музыка в терминале

Лёгкий консольный плеер VK Музыки в стиле Spotify. Один файл без зависимостей (~8 МБ), за звук отвечает [mpv](https://mpv.io).
Вместе плеер и mpv занимают около 50–60 МБ памяти, в простое процессор почти не нагружается.

## Установка

Все файлы лежат на странице [Releases](https://github.com/vildangil/vk-music-tui/releases). Команда для запуска везде одна и та же: `vktui`.

### Windows
Скачай `vk-music-tui-setup-amd64.exe` (для ARM-ноутбуков `-arm64`, для старых 32-битных систем `-386`) и запусти его.
- Права администратора не нужны: программа ставится в `%LOCALAPPDATA%\Programs\vk-music-tui`.
- Можно выбрать ярлык на рабочем столе (включён по умолчанию), добавление в PATH и установку mpv через winget.
- Музыка, офлайн-библиотека и кэш хранятся в папке программы (`music`, `offline`, `cache`). При удалении стирается только кэш, твоя музыка остаётся.

Или одной командой в PowerShell (тоже создаёт ярлыки):
```powershell
irm https://raw.githubusercontent.com/vildangil/vk-music-tui/main/install/install.ps1 | iex
```

### macOS
Скачай `vk-music-tui-<версия>.pkg` и открой его. Установится команда `vktui` и приложение «VK Music TUI» в «Программах» (открывает плеер в Терминале). Если есть Homebrew, установщик сам поставит mpv, иначе выполни `brew install mpv`.
Установщик не подписан: при первом открытии нажми на файл правой кнопкой → «Открыть».

### Linux
Готовые пакеты `vk-music-tui` для x86_64, arm64, armv7 и x86. mpv подтянется как зависимость.

| Дистрибутив | Пакет | Установка |
|---|---|---|
| Debian, Ubuntu, Mint, Pop!_OS | `.deb` | `sudo apt install ./vk-music-tui_*_amd64.deb` |
| Fedora, openSUSE, RHEL | `.rpm` | `sudo dnf install ./vk-music-tui-*.x86_64.rpm` (mpv из RPM Fusion) |
| Arch, Manjaro, EndeavourOS | `.pkg.tar.zst` | `sudo pacman -U vk-music-tui-*-x86_64.pkg.tar.zst` |
| Alpine | `.apk` | `sudo apk add --allow-untrusted vk-music-tui_*.apk` |
| Любой (и FreeBSD, Termux) | скрипт | `curl -fsSL https://raw.githubusercontent.com/vildangil/vk-music-tui/main/install/install.sh \| sh` |

Пакеты добавляют пункт «VK Music TUI» в меню приложений. Музыка, офлайн-библиотека и загрузки лежат в `~/Музыка/VK Music` (`~/Music/VK Music`).

### Вручную
Скачай архив под свою систему из Releases, положи `vktui` в любую папку из PATH и установи mpv:

| Система | mpv |
|---|---|
| Windows | `winget install shinchiro.mpv`, `scoop install mpv` или `mpv.exe` рядом с `vktui.exe` |
| macOS | `brew install mpv` |
| Debian/Ubuntu | `sudo apt install mpv` |
| Arch | `sudo pacman -S mpv` |
| Fedora | `sudo dnf install mpv` (из RPM Fusion) |
| Termux | `pkg install mpv` |

## Первый запуск

```sh
vktui
```
Плеер предложит войти:

1. **По коду (рекомендуется).** Вводишь телефон или email, VK присылает код по SMS, в уведомлении приложения или звонком. Так же входит официальное приложение VK. Если на аккаунте нужен пароль, плеер его спросит.
2. **Логин и пароль.** Поддерживаются 2FA и капча.
3. **Через браузер (Kate Mobile).** Старый способ: сейчас VK часто не даёт таким токенам доступ к музыке.
4. **Готовый токен.**

Токен хранится только у тебя:
- Windows: `%APPDATA%\vktui\config.json`
- Linux: `~/.config/vktui/config.json`
- macOS: `~/Library/Application Support/vktui/config.json`

## Управление

| Клавиша | Действие |
|---|---|
| `↑/↓`, `j/k` | перемещение по списку |
| `PgUp/PgDn`, `g/G` | на страницу вверх/вниз, в начало/конец |
| `Enter` | играть трек / открыть плейлист |
| `Space` | пауза |
| `n` / `p` | следующий / предыдущий трек |
| `←/→` (`h/l`) | перемотка на 5 с |
| `Shift+←/→` (`H/L`) | перемотка на 30 с |
| `+` / `-` | громкость |
| `s` | перемешивание |
| `r` | повтор: выкл → весь список → один трек |
| `/` | поиск |
| `1`…`7` | разделы: Моя музыка, VK Микс, Рекомендации, Популярное, Поиск, Плейлисты, Настройки |
| `Tab` | переключение между меню и списком |
| `Esc` / `Backspace` | назад из плейлиста |
| `a` | добавить трек в «Мою музыку» |
| `t` | показать / скрыть текст песни |
| `[` / `]` | листать текст песни |
| `o` | очередь (что играет дальше) |
| `Shift+P` / `Shift+S` | играть весь список по порядку / перемешанным |
| `Ctrl+R` или `F5` | обновить текущий раздел (в VK Миксе — новая подборка) |
| `d` | скачать выбранный трек в mp3 |
| `Shift+D` | скачать весь список (нажать дважды) |
| `c` | перейти к играющему треку |
| `q` | выход |

**Мышь.** Клик по разделу слева открывает его. Клик по треку выделяет его, двойной клик запускает. Колесо прокручивает список, а над панелью плеера меняет громкость. Ползунок на полосе прогресса можно тащить мышкой (или просто кликнуть в нужное место). Кнопки `|◀` `▶` `▶|`, `shuffle`, `repeat`, `−` и `+` в панели плеера тоже нажимаются.

**VK Микс.** Бесконечный персональный поток, как в официальном приложении. Когда заканчивается любая очередь, плеер сам продолжает играть Микс (это отключается в настройках).

**Настройки (`7`).** Эквалайзер на 10 полос с пресетами (Бас+, Рок, Электроника, Вокал и др.) и своим режимом, выравнивание громкости между треками, автопродолжение Миксом, шаг громкости и цвет оформления. Меняются стрелками или кликом и сохраняются между запусками.

**Текст песни (`t` или кнопка «текст»).** Панель справа открывается и закрывается в любой момент. Где есть синхронный текст, он «живой»: текущая строка подсвечивается, панель прокручивается сама, а клик по строке перематывает песню к ней. Источники по очереди: VK, [LRCLIB](https://lrclib.net) (открытая база синхронных текстов), Genius (обычный текст). Найденные тексты кешируются в папке конфига.

**Очередь (`o` или клик по «Очередь» слева).** Показывает текущий трек и всё, что заиграет дальше, в настоящем порядке — с учётом перемешивания. Enter или двойной клик переходит к выбранному треку, не пересобирая очередь.

**Длинный текст** листается колесом мыши или `[` / `]`, справа видна полоса прокрутки. Синхронный текст после ручной прокрутки 10 секунд не дёргается, потом снова следует за песней (или сразу — по `c`). В паузах без слов три точки постепенно «наполняются» за время паузы.

**Иконки Nerd Font.** Если в терминале стоит шрифт из [Nerd Fonts](https://www.nerdfonts.com) (например, JetBrainsMono Nerd Font), плеер рисует иконки вместо текстовых значков. По умолчанию выключены — всё работает без установки шрифтов. Если включить их без Nerd Font в терминале, вместо значков будут квадратики.

**Любая раскладка.** Горячие клавиши работают и в русской/украинской раскладке: `й` = `q`, `ы` = `s`, `е` = `t` и т. д.

**Играть / Перемешать.** В заголовке любого списка треков есть кнопки `[▶ Играть]` и `[Перемешать]` — запускают весь список сразу, не нужно выбирать трек.

**Разделы не перезагружаются.** Загруженные разделы остаются в памяти: переключился на «Популярное» и обратно — «Моя музыка» на месте, с тем же положением в списке. Обновить вручную — `Ctrl+R`.

**Скачивание и кэш.** `d` сохраняет трек в mp3 (320 кбит/с, с названием, исполнителем и альбомом в тегах): на Windows в папку `music` рядом с программой, на Linux и macOS в «Музыка/VK Music»; скачанные треки помечены `↓` и играют без интернета. Ещё плеер тихо кэширует то, что ты слушаешь: при повторе трек стартует мгновенно и тоже работает офлайн. Размер кэша (по умолчанию 1 ГБ, старое удаляется само), его включение и папка загрузок — в Настройках. Для скачивания нужен только mpv, ffmpeg не требуется.

**Несколько аккаунтов.** Настройки → «Аккаунт»: стрелками или из списка переключаешься между аккаунтами, там же «Добавить аккаунт». Из терминала: `vktui login` добавляет аккаунт, `vktui accounts` показывает список, `vktui switch 2` переключает, `vktui logout` выходит из текущего.

**Меню в настройках.** Enter или клик по пункту с несколькими значениями (эквалайзер, источник текста, размер кэша, шаг громкости, цвет, аккаунт) открывает список, из которого можно выбрать. Стрелки ←/→ по-прежнему листают значения на месте.

**Источник текста.** Авто (VK → LRCLIB → Genius) или только один из них. Выбирается в Настройках или кликом по заголовку панели текста.

**Вся музыка офлайн.** Кнопка `[↓ Сохранить офлайн]` в «Моей музыке» (или пункт в Настройках) сохраняет на диск все треки — навсегда, в отличие от кэша. Новые треки, которые ты добавляешь в VK, докачиваются сами, а прогресс видно на кнопке («Офлайн 120/266»). Если интернета нет или VK недоступен, плеер откроет «Мою музыку» из сохранённого и будет играть с диска. Файлы лежат в папке `offline` рядом с программой (Windows) или в `~/Music/VK Music/.offline` (Linux, macOS).

**VK Микс → [Обновить]** (или `Ctrl+R`) — новая подборка.

**Вся музыка сразу.** «Моя музыка» и плейлисты подгружаются целиком в фоне, а в очередь попадают все треки, не только первые 200.

**Медиа-панель системы.** На Windows (и macOS) текущий трек виден во всплывающей панели громкости: название, исполнитель и альбом. Кнопки «пауза», «следующий» и «предыдущий» в ней работают, как и мультимедийные клавиши клавиатуры. Для этого нужен mpv 0.38 или новее.

## Команды

```
vktui            запустить плеер
vktui login      войти (добавить ещё один аккаунт)
vktui accounts   список аккаунтов
vktui switch N   переключиться на аккаунт N
vktui logout     выйти из текущего аккаунта
vktui doctor     диагностика: mpv, сеть, токен, аудио, папки
vktui version
```

## Если не работает

Сначала запусти `vktui doctor`: он покажет, что именно сломано.

**`нет связи с VK` / `EOF` при включённом VPN.** VPN или прокси-клиент (Throne, Nekoray, v2rayN, Hiddify…) пускает трафик VK через зарубежный сервер, а VK такие соединения часто обрывает. Пусти VK напрямую одним из двух способов.

*По доменам.* Добавь в правила маршрутизации с действием **direct**:
```
vk.com
vk.ru
userapi.com
vkuser.net
vkuseraudio.net
vk-cdn.net
mycdn.me
okcdn.ru
ok.ru
vk.me
vkontakte.ru
```
Музыку VK сейчас раздаёт в том числе через CDN Одноклассников (`okcdn.ru`). Если API работает, а треки не играют («loading failed», «SSL connect error»), значит, не хватает именно этого домена.
В Throne: **Настройки → Маршрутизация** (Routing). Создай или отредактируй профиль маршрутов и добавь правило: тип `domain_suffix`, значения из списка выше, outbound `direct`. Профиль должен быть активным. В старом интерфейсе (как в Nekoray) это вкладка **Custom → Direct**, где каждая строка выглядит как `domain:vk.com`.

*По процессам*, если клиент работает в режиме TUN. Правило `process_name` со значениями `vktui.exe` и `mpv.exe` (на Linux и macOS `vktui` и `mpv`), outbound `direct`.

**`Токен недействителен`, `Доступ к аудио запрещён` или `Unknown method passed`.** Выполни `vktui login` и выбери вход по коду. Музыку VK отдаёт только токенам официальных приложений.

**`Flood control`.** VK временно ограничил число запросов. Подожди несколько минут и не входи заново много раз подряд.

**`mpv не найден`.** Установи mpv (см. таблицу выше) или укажи путь к нему: `VKTUI_MPV=/путь/к/mpv vktui`.

**Кракозябры или квадратики вместо символов на Windows.** Запускай плеер в Windows Terminal, а не в старой консоли `cmd.exe`.

## Сборка из исходников

Нужен Go 1.26 или новее.
```sh
go build -trimpath -ldflags "-s -w" -o vktui .
```
Релиз собирается сам при пуше тега `v*`: GoReleaser делает архивы и пакеты для Linux, а Inno Setup — установщик для Windows.

## Как это устроено

- `internal/vk`: минимальный клиент VK API (`audio.get`, `audio.search`, `audio.getRecommendations`, `audio.getPopular`, `audio.getPlaylists`, `audio.getById`, `audio.add`) и вход от имени официального приложения VK для Android (по коду, как в Music-M), а также старый вход через Kate Mobile.
- `internal/player`: управление mpv через JSON IPC (named pipe на Windows, unix-сокет на остальных системах). mpv завершается вместе с плеером, даже если просто закрыть окно терминала.
- `internal/ui`: интерфейс на [Bubble Tea](https://github.com/charmbracelet/bubbletea).

Ссылки на треки в VK со временем протухают. Плеер сам запрашивает свежую ссылку и только потом пропускает трек.
